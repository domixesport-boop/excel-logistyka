2. Jak zbudowany jest arkusz?

Excel działa jak ogromna tabela. Każde pole to komórka. Kolumny oznaczane są literami, a wiersze liczbami.

KOLUMNA

A, B, C, D...

Pionowy zestaw komórek. Np. kolumna C może przechowywać ilość towaru.

WIERSZ

1, 2, 3, 4...

Poziomy zestaw komórek. Jeden wiersz może opisywać jeden produkt.

KOMÓRKA

np. C4

Przecięcie kolumny C z wierszem 4. Każda komórka ma własny adres.

ARKUSZ

Arkusz1

Jedna karta skoroszytu. Plik Excela może mieć wiele arkuszy.

4. Typy danych w Excelu

W komórkach możemy przechowywać różne rodzaje informacji. Excel inaczej traktuje tekst, liczby i daty.

Tekst

np. „Paleta EUR”, „Magazyn A”, „LOG001”

Liczba

np. 25, 120, 4,90

Data

np. 22.10.2026

Formuła

Zaczyna się znakiem =, np. =C2*D2.
